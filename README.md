# DermoCare Slot Reservation System

DermoCare Slot Reservation System is a static dermatology clinic website designed to present the clinic's advanced skincare and laser treatment services in a clear, modern, and user-friendly way. The project includes a homepage with treatment cards, navigation, clinic information, contact details, and dedicated pages for CO2 Laser Treatment and Carbon Laser Peel Treatment. Each treatment page provides an overview of the procedure, its primary indications, treatment duration, buffer time, and pre-procedure requirements, helping patients understand the service before making an appointment. The website uses responsive HTML and CSS layouts, local treatment images, Font Awesome icons, and linked detail pages to create a simple and accessible browsing experience for prospective patients.
